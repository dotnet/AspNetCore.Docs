### Add route template

Update the Edit, Details, and Delete Razor Pages to use the `{id:int}` route template. Change the page directive for each of these pages from `@page` to `@page "{id:int}"`. Run the app and then view source.

The generated HTML adds the ID to the path portion of the URL:

```html
<td>
  <a href="/MoviePages/Edit/1">Edit</a> |
  <a href="/MoviePages/Details/1">Details</a> |
  <a href="/MoviePages/Delete/1">Delete</a>
</td>
```

A request to the page with the `{id:int}` route template that doesn't include the integer returns an HTTP 404 (not found) error. For example, `https://localhost:7247/MoviePages/Details` returns a 404 error. To make the ID optional, append `?` to the route constraint:

```cshtml
@page "{id:int?}"
```

Test the behavior of `@page "{id:int?}"`:

1. Set the page directive in `Pages/MoviePages/Details.cshtml` to `@page "{id:int?}"`.
1. Set a break point in `public async Task<IActionResult> OnGetAsync(int? id)`, in `Pages/MoviePages/Details.cshtml.cs`.
1. Navigate to `https://localhost:7247/MoviePages/Details/`.

### Posting and binding review

Examine the `Pages/MoviePages/Edit.cshtml.cs` file:

When you make an HTTP GET request to the `MoviePages/Edit` page, for example, `https://localhost:7247/MoviePages/Edit/3`:

* The `OnGetAsync` method fetches the movie from the database and returns the `Page` method.
* The `Page` method renders the `Pages/MoviePages/Edit.cshtml` Razor Page. The `Pages/MoviePages/Edit.cshtml` file contains the model directive `@model RazorPagesMovie.Pages.MoviePages.EditModel`, which makes the movie model available on the page.
* The Edit form displays the values from the movie.

When you post the `MoviePages/Edit` page:

* The form values on the page bind to the `Movie` property. The `[BindProperty]` attribute enables [Model binding](../../mvc/models/model-binding.md).

  ```csharp
  [BindProperty]
  public Movie Movie { get; set; }
  ```

* If there are errors in the model state, for example, `ReleaseDate` can't convert to a date, the form redisplays with the submitted values.
* If there are no model errors, the movie is saved.

The HTTP GET methods in the Index, Create, and Delete Razor pages follow a similar pattern. The HTTP POST `OnPostAsync` method in the Create Razor Page follows a similar pattern to the `OnPostAsync` method in the Edit Razor Page.
